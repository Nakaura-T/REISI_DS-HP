# 中浦研究室HP：スキル共通の前提

## サイトの目的

熊本大学・中浦 猛教授の研究室HP原案。主な読者は配属・進学・見学を検討する学生。研究内容と業績の蓄積を伝え、研究への関心と問い合わせにつなげる。共同研究を検討する研究者にも研究領域と連絡先が分かるようにする。

ユーザーからの新しい指示を優先し、このメモは確定した範囲を引き継ぐために使う。

## 技術構成

- `index.html`・`styles.css`・`main.js`・`favicon.svg`の静的サイト。
- GitHub Pagesで公開でき、ビルドやJavaScriptなしでも本文と主要機能が利用できる構成。
- スキルにReact・Tailwindなどの用語があっても、スキル導入のための技術移行は行わない。
- 色やレイアウトは原案であり、変更依頼があれば検討する。スキルの導入だけではサイトの変更は行わない。

## 内容の優先順位

1. 主資料はプロジェクトルートの `Paper_Data/citations.txt`。CSVは一部の業績のみ。
2. 研究業績は学生募集に重要。最近の生成AIに偏らず、初期のCT・SPECT画像融合、造影剤量・被ばく低減、画像再構成、機械学習から現在へのつながりを伝える。
3. 代表業績は筆頭・第2著者を中心とし、著者順を明示。第2著者という事実だけから責任著者や指導担当と推定しない。
4. 論文の全件検索・絞り込みページは不要。全業績はGoogle Scholarへのリンクで案内する。
5. 出版年、誌名、著者順などの根拠と提案文の区別は `CONTENT_NOTES.md` に記録する。
6. 提供TXTには重複や訂正記事などがあるため、エントリ数を論文総数として表示しない。
7. 引用数、研究成績、受賞、写真、学生人数、受け入れ条件を補完・捏造しない。実際の医療画像でない抽象図は概念表現として扱う。

## スキルの適用

2026-09-10にユーザーが、医療系の信頼感とデータサイエンスの先進性を両立するデザインへの変更を希望。白・濃紺・青を基調とし、研究対象が分かる概念図と具体的な論文紹介を使う。文章は抽象的なキャッチコピーを減らし、研究対象・比較方法・相談先を自然な日本語で伝える。改訂内容と図の扱いは `CONTENT_NOTES.md` を参照。

視覚上の一般則より、ユーザーの依頼と実際の読者・内容を優先する。日本語の文字組みと長い論文タイトルを確認する。デザイン方向性を変える場合は、目的に合う理由を短く示してから取り組む。

スキルを入れただけでモデル自体が再学習されるわけではなく、必要な作業時に指示セットを読み込んで使用する。
